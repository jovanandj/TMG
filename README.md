# TMG: Topic Modeling Graph for Social Media Sentiment Prediction

## Overview
This repository provides the implementation of **TMG (Topic Modeling Graph)**, a framework for predicting social media users' emotional responses to mass shooting events. TMG combines topic modeling of pre-event posts with graph neural networks to capture user-level interactions and improve predictive performance.
